# URLog Updates

유어로그(URLog)의 암호화 자동 업데이트 전용 저장소입니다.

- 0.9.x: 업데이트 검증용 사전 릴리스
- 1.0.x: 정식 릴리스
- `.urupdate`는 기존 URLog 앱에서 검증·복호화해 적용합니다. 직접 실행하는 파일이 아닙니다.
- 처음 설치할 실행 파일은 구매한 배포처에서 받으세요. 업데이트에 별도 가입이나 키 입력은 필요하지 않습니다.
- 원본 실행 파일과 애플리케이션 소스 코드는 이 저장소에 공개하지 않습니다.

This repository contains encrypted update payloads and signed update metadata for URLog.
It does not distribute the application source code or original executables.
